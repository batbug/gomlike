GomLike: видеоплеер «как GOM», без рекламы и без обновлений
============================================================

Внутри: настройки для mpv (быстрый open-source плеер, играет всё),
своя классическая панель управления под видео (тёмная, с оранжевым
акцентом) и меню по правому клику (из оболочки uosc).
Плеер никуда не ходит в интернет и ничего не обновляет сам.

УСТАНОВКА И УДАЛЕНИЕ
Плеер ставится установщиком GomLike-Setup.exe в выбранную папку,
там же лежат все настройки. Удалить: Пуск -> GomLike -> Uninstall
или «Установленные приложения» в параметрах Windows.
Обновлять ничего не нужно. Если когда-нибудь захочешь свежий mpv,
просто запусти установщик ещё раз в ту же папку.

ГОРЯЧИЕ КЛАВИШИ (работают и в русской раскладке)
  Пробел, клик по видео   пауза
  Enter, двойной клик   полный экран;  Esc  выйти из него
  Двойной клик по пустому окну   открыть файл
  Правый клик       меню, как в GOM (обычное меню Windows)
  Колесико (клик), F8   плейлист: все видео из той же папки
  ← →               перемотка 5 сек
  Ctrl + ← →        30 сек
  Shift + ← →       1 мин
  F / D             кадр вперёд / назад
  ↑ ↓, колесо мыши  громкость (до 200%)
  M                 без звука
  C / X / Z         быстрее / медленнее / обычная скорость
  PgUp / PgDn       предыдущий / следующий файл в папке
  Ctrl+O            открыть файл
  < / >             сдвиг субтитров на 0.5 сек;  ?  сброс
  Alt+H             показать/скрыть субтитры
  Alt+L             сменить субтитры;  Alt+S  меню субтитров
  Alt+A             меню звуковых дорожек
  F7                настройки изображения: яркость, контраст,
                    насыщенность, гамма, оттенок, поворот, отражение
  1/2  3/4          контраст − / +,  яркость − / +
  5/6  7/8          гамма − / +,  насыщенность − / +
  Нампад + / −      приблизить / отдалить картинку
  Нампад 1-9        сдвинуть картинку (7 9 1 3 по диагонали);
                    нампад 5  вернуть как было
  A                 пропорции 16:9 / 4:3 / 2.35:1 / как в файле
  Alt+1..4          размер окна 50% / 100% / 150% / 200%
  Ctrl+E            скриншот на рабочий стол
  Tab               информация о файле и кодеках

Ещё: плеер запоминает, где ты остановился, сам подхватывает
субтитры и звуковые дорожки рядом с видео, а в конце файла
переходит к следующему в папке.

НАСТРОЙКА
Всё лежит в portable_config:
  mpv.conf      общие настройки (с комментариями на русском)
  input.conf    горячие клавиши (поменять: КЛАВИША команда)
  script-opts\classicbar.conf   цвета и высота панели, автоскрытие
  menu.conf     пункты меню по правому клику
  script-opts\uosc.conf   запасное меню субтитров и звука (если курсор вне окна)

Панель: клик по времени переключает общее/оставшееся время,
клик по «1.2x» сбрасывает скорость. В полноэкранном режиме
панель прячется и появляется при движении мыши.

Настройки изображения (F7), масштаб и сдвиг нампадом действуют
на все файлы до закрытия плеера. Клавиши можно зажимать.
В панели F7 клик по числу сбрасывает ползунок, колесо мыши над
ползунком двигает его.

В полноэкранном режиме подведи мышь к верху экрана: появится
полоса с названием файла и кнопками «выйти из полного экрана»,
«свернуть», «развернуть в окно» и «закрыть».
