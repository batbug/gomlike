# GomLike — что осталось сделать

Этот файл для следующей сессии Claude Code (и для меня самого). Описание проекта и структуры лежит в `README.md`.

## 1. Сначала: git и GitHub

Файлы проекта лежат здесь, но git-репозитория ещё нет: из облачной сессии запись в `.git` запрещена, поэтому туда приехали только сами файлы.

1. `git init -b main`
2. Проверить `.gitignore`: собранный `installer/GomLike-Setup.exe` не коммитим, а `player/portable_config/scripts/uosc/bin/ziggy-windows.exe` коммитим (это часть uosc).
3. Первый коммит, например «GomLike: mpv-based player with classic panel, playlist, and NSIS installer».
4. Создать **приватный** репозиторий и запушить: `gh repo create gomlike --private --source=. --push`.

## 2. Проверить на настоящей Windows

В облаке это проверялось только в Linux-сборке mpv 0.37 и в Wine, поэтому на живой Windows нужно убедиться:

- [ ] **Окно выбора файла.** Двойной клик по пустому окну, Ctrl+O и кнопка-папка на панели. Окно вызывается через PowerShell + WinForms (`open_dialog()` в `scripts/classicbar.lua`). Проверить, что окно появляется поверх плеера, что работает выбор нескольких файлов и что пути с русскими буквами открываются.
- [ ] **Плейлист из папки.** Нажатие на колесико или F8. Список собирает сам mpv опцией `autocreate-playlist=same` в `mpv.conf`, она есть только в свежих версиях mpv (в 0.37 её нет). Проверить, что при открытии одного файла в списке оказываются все видео из его папки.
- [ ] **Установщик.** Скачивание mpv (`installer/getmpv.ps1`), ярлыки, удаление.
- [ ] **Ассоциации файлов.** Установщик удаляет `UserChoice` у форматов, чтобы GomLike стал плеером по умолчанию вместо GOM. Проверить на Windows 10/11, что видео действительно открываются в GomLike без вопроса «Как открыть?».
- [ ] **SmartScreen.** Установщик не подписан, ожидаемо будет предупреждение. Ничего не делаем, просто знаем.
- [ ] **HiDPI (125%/150%).** Размеры панели, подсказок и плейлиста.
- [ ] **Клик по видео.** Одиночный клик ставит паузу, двойной переключает полный экран, при этом пауза не должна дёргаться. Root ещё не подтвердил, что в GOM было именно так.

## 3. Известные недочёты

- Ширина текста в панели считается приблизительно (`text_w()`), поэтому подсказки и обрезка длинных названий в плейлисте иногда чуть мимо.
- Меню по правому клику, выбор субтитров и звуковых дорожек всё ещё делает uosc. Его панель, таймлайн и прочие элементы отключены в `script-opts/uosc.conf`. Если когда-нибудь захочется избавиться от uosc целиком, эти меню придётся написать в `classicbar.lua`.
- `tools/build.sh` рассчитан на Linux (bash + `makensis`). Для сборки на Windows стоит добавить `tools/build.ps1` (NSIS для Windows: `winget install NSIS.NSIS`).
- uosc лежит в репозитории как есть. Перед тем как делать репо публичным, нужно проверить его лицензию и указать её.
